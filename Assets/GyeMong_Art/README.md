# GyeMong_Art
계몽 프로젝트 아트 리소스 리포지토리. 공유 금지.

# How to Use?
Unity GyeMong 프로젝트 안의 Assets/ 폴더 내에 이 폴더를 넣고 실행하면 됩니다.

# Description
/Art : 아트 리소스들을 저장하는 공간입니다.
    /Rune : 룬 이미지들과 테두리 이미지들을 저장하는 곳입니다.
    /Season : 룬 UI의 계절 이미지들을 저장하는 곳입니다.
    /Tile : 타일에 쓰인 이미지들을 저장하는 곳입니다.
/Sound : 사운드 리소스들을 저장하는 공간입니다.
/PurchasedAsset : 구매한 에셋들의 원본을 저장하는 공간입니다.
    /InfinityPBR : RPG SFX 에셋입니다.
    /Pixel Art : RPG VFX 에셋입니다.
